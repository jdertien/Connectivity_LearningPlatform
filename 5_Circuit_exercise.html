6  Circuitscape Exercise in R

6.1 Circuitscape Analysis [Under construction!]

Now that we have seen how to perform least-cost path exercises in QGIS and R, we will move on to operating and understanding circuit-theory models. Where least-cost path models create a single path between a pair of points (e.g. between two protected areas), circuit-theory models, such as Circuitscape, create many potential paths that could be create via “random-walking” simulations. This is likely a more realistic representation of how wildlife interact and move through their environment.

The R library ‘circuitscaper’ provides an R-native interface to the most recent versions of Circuitscape and Omniscape. These two programs are written in the Julia code language therefore you will first need to download Julia using the ‘circuitscaper’ function cs_install_julia() or if you prefer download Julia directly from the code language’s official website. We will get started just like in the least-cost path analysis by loading in and sub-setting our data.


#As with all R packages, you will initially need to use install.packages("circuitscaper") in order to install the package on your computer. 

library(circuitscaper)
library(terra)
library(sf)

resist = rast("./data/balkan_predenergy_resist.tif")

pts = st_read("./data/PA_balkan_subset_pts2.shp")

6.1.1 Running Circuitscape

We will convert the points into coordinates since ‘circuitscaper’ accepts a two-column matrix or data frame of x/y coordinates and internally converts those locations to focal node raster cells. Then we run Circuitscape from our one origin point (protected area) to all our destination points. It is useful to first run ?cs_one_to_all() to see the defaults of all the parameters running in the Circuitscape call.

#Currently the analysis is only saving the cumulative of all the pair-to-pair current density calculations. 
#If you want to save each pair's directional connectivity calculation change cumulative_only = FALSE .

cs_result = cs_one_to_all(
  resistance = resist,
  locations = coords,
  resistance_is = "resistances",
  cumulative_only = TRUE
)

#Check out the cumulative current results and then plot the data

Higher values identify areas that are receiving more current across between and within protected areas in your network. Ecologically this can indicate the more important areas for wildlife movement or where connectivity corridors are being highly compressed and possibly under threat from being cutoff.

We can identify potential hotspots for connectivity by isolating the highest percentile values of current density.

current = cs_result$cumulative_current

vals = values(current, mat = FALSE)

vals = vals[is.finite(vals) & vals > 0]

#This will identify the top 10% value threshold
threshold_90 = quantile(
  vals,
  probs = 0.90,
  na.rm = TRUE
)

threshold_90
#>        90% 
#> 0.02753721

hotspots10 = current >= threshold_90

plot(hotspots10,
  main = "Top 10% Current-Density Hotspots"
)

plot(st_geometry(focal_pts),
  add = TRUE,
  pch = 16,
  col = "red"
)

Isolating other threshold values is rather simple. If you want to identify the top 5% or top 25% just change the threshold_90 object, respectively:

threshold_95 = quantile(vals, 0.95)

threshold_75 = quantile(vals, 0.75)

These different rasters can be overlaid in one plot to easily see transitions in the hotspot areas.
